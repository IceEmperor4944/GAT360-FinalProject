# GAT360-FinalProject

☁️ Sky Dash - 3D Cloud Platform Adventure
An exhilarating 3D platformer where you dash through floating platforms high above the clouds! Master the art of aerial movement, chain together spectacular dash combos, and soar through breathtaking sky-bound environments.

✨ Features

Dynamic Dash Mechanics: Chain together air dashes with precise timing and direction
3D Aerial Movement: Full 6-degrees of freedom platforming in stunning cloud environments
Momentum-Based Physics: Realistic physics with momentum conservation and gravity
Floating Platform Networks: Navigate through interconnected cloud platforms

🎮 Gameplay Mechanics
Core Movement

WASD: Basic movement
Mouse: Camera control and aiming dash direction
Space: Jump
Shift: Dash (directional based on camera/movement input)

🛠️ Development
Level Design Tools

Custom Unreal Editor tools for platform placement
Platform optional checkpoint

🎨 Art & Technical Details

Rendering: Unreal Engine 5 with Lumen global illumination
Cloud Rendering: Volumetric fog and cloud materials
Physics: Custom dash mechanics built on base platforming character Physics
Audio: 3D spatial audio with background music
VFX: Niagara particle systems for dash trails and environmental effects

🏆 Level Editor
Access the built-in level editor through the main menu to create custom cloud platforms and dash challenges.
Editor Features

Drag-and-drop platform placement
Real-time physics testing
